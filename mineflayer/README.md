# Mineflayer 端到端测试

测试会启动真实 Paper 1.21.4 服务端，并连接一个离线模式的 Mineflayer 机器人。它验证：

- 协议登录和插件加载；
- 1/39/40/79/80/119/120/121/122 层主题边界；
- 同日布局和已挖状态保持不变，跨日布局哈希变化；
- 入口附近的生成方块对真实客户端可见；
- 机器人实际调用 `bot.dig()` 挖掉最后一块测试石头并触发梯子；
- 右键梯子后到达下一层；
- 第 120 层个人奖励和骷髅钥匙确实进入背包；
- 所有玩家主动离开或被外部传送出去后，骷髅洞会话种子发生变化。

环境要求：Java 21、Node.js 22+、PowerShell。请从项目根目录运行：

```powershell
.\scripts\run-e2e.ps1
```

脚本通过 SHA-256 固定 Paper `1.21.4-232`，通过 `package-lock.json` 固定 Mineflayer `4.38.0`。Paper 下载和运行缓存位于 `e2e/cache/`、`e2e/runtime/`；失败诊断会写入 `e2e/artifacts/`，这些目录均不会提交到 Git。

自动化服务器只绑定 `127.0.0.1` 并使用 `online-mode=false`。该配置仅供隔离测试，禁止直接用于公网服务器。

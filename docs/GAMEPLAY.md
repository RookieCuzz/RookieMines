# 菜鸟矿洞玩法说明

## 地图到底是不是随机生成

普通矿洞 1–119 层与骷髅洞 122 层以后都是程序化生成，不需要导入现成地图、结构文件或资源包。每层种子由以下信息共同决定：

```text
矿洞世界种子 + 生成周期 + 楼层号 + 生成规则版本 + 生成配置
```

普通矿洞的“生成周期”是主世界游戏天数。因此同一服务器、同一天、同一楼层会得到同一布局；该层第一次生成后，玩家挖矿、杀怪和找到梯子的状态会写入磁盘，当天重进不会还原。游戏日变化不会把正在探索的玩家突然卡在失效地图中；下一次有人请求旧楼层时，层内玩家会先被安全转移，随后用新种子重建并统一送回。

骷髅洞使用“会话编号”代替游戏天数。只要仍有玩家留在骷髅洞，大家共享本次会话的楼层；最后一名玩家离开后，会话编号递增，下一次进入得到新布局。

只有两个例外：

- 第 120 层是代码构建的固定终点奖励室；
- 第 121 层是代码构建的固定骷髅洞大厅。

它们仍由插件直接放置方块，并不是随仓库附带的地图文件。

| 80–119 | `LAVA` 熔岩矿区 | 黑石、玄武岩、岩浆块 | 金、红石、钻石 | 岩浆怪、骷髅 |

骷髅洞越深，远古残骸权重会缓慢增加，并在达到上限后停止增长。

## 单层会生成什么

普通程序化楼层会从中心安全区向外雕刻连通洞穴，再按主题填充：

- 基岩封闭的地板、天花板和外墙，避免玩家直接穿出楼层；
- 低频高度场生成的起伏地面与拱形穹顶，洞心通常更高、墙边通常更低；
- 三维墙面凹口以及从地面或顶面伸出的主题岩柱，打破垂直平墙；
- 泥土矿区墙边少量蜘蛛网，骷髅洞中更密集；冰雪和熔岩矿区默认没有蜘蛛网；
- 带照明的平坦安全出生区，出生点保留至少三格空气净空；
- 可行走地面的相邻高差最多一格，保证主洞穴能从入口步行探索；
- 主题矿物、明暗石材、火把或灵魂火把；
- 概率水池或熔岩池；
- 概率特殊房间、普通木桶和骷髅洞宝箱；
- 按开放区域面积计算的怪物，且不会生成在出生安全区附近；
- 一定概率出现的暗层。

蜘蛛网只会挂在远离出生区的墙边高处，地面以上保留完整三格净空，并避开水池、容器和已知出口，因此不会挡住正常行走与跳跃。水池与特殊房间会局部整理地面；特殊房间会选择与主洞穴同高的入口，并为入口保留可行走空间。灯、容器和怪物则使用所在位置的实际站立高度。奖励层不会生成普通怪物。尺寸、暗层概率、怪物密度、池塘、特殊房间概率、蜘蛛网密度和洞穴起伏均可在 `config.yml` 调整。第 120、121 层是人工建筑风格的固定房间，不使用自然洞穴起伏或蜘蛛网。

## 如何下楼

挖掘计数石材时，插件按下式计算本次出现梯子的概率：

```text
基础概率
  + 1 / 剩余石头数
  + 幸运效果等级 / 100
  + 当日运气 / 5
  + 清空怪物奖励
```

结果会限制在 `0–100%`；剩余石头为 0 时必定出现梯子。矿层怪物被击杀时也有机会出现梯子，最后一个怪物死亡时必定触发。右键生成的橡木活板门即可进入下一层。

骷髅洞的出口有概率成为跳坑：通常跳过 3–8 层，小概率跳过 5–15 层，并按跳层数扣除生命值，但最低保留 1 点生命。

## 电梯与个人进度

插件记录每名玩家到达过的最深普通矿层，并向下取整为 5 的倍数作为最深电梯检查点。玩家身处普通矿洞 1–120 层时，可以使用：

```text
/rmine elevator
```

这会打开 45 格电梯菜单，完整显示第 1 层和第 5、10、15……120 层：绿色矿车是当前楼层，矿石图标表示已解锁，灰色玻璃表示尚未解锁。点击可达楼层即可传送；点击锁定楼层不会移动，也不会提前生成该层。第 121 层大厅和第 122 层后的骷髅洞不允许打开普通矿洞电梯。

原来的直接命令仍然保留。例如到达第 27 层后，可以不打开菜单直接前往第 25 层：

```text
/rmine elevator 25
```

玩家进度保存在 `plugins/RookieMines/players.yml`。管理员使用 `/rmine admin goto` 进入普通矿层时也会更新该管理员自己的最深记录。

每名玩家同一时间只保留一个正在生成的目标楼层。若连续选择不同目标，以最后一次有效请求为准；较早楼层稍后生成完成时不会把玩家拉回去。关闭菜单、离开矿洞或退出服务器都会清理对应的临时操作状态。

## 阶段奖励

奖励按玩家独立记录，每个楼层只能领取一次：

| 楼层 | 奖励 |
| --- | --- |
| 10 | 皮革靴子 |
| 20 | 铁剑 |
| 40 | 弓 |
| 50 | 铁靴子 |
| 60 | 钻石剑 |
| 70 | 弩 |
| 80 | 钻石靴子 |
| 90 | 下界合金剑 |
| 100 | 附魔金苹果 |
| 110 | 下界合金靴子 |
| 120 | 骷髅钥匙 |

第 120 层给出的物品是带有插件持久化标记并命名为 `Skull Key` 的原版试炼钥匙。普通试炼钥匙不能代替它。持有该钥匙后使用 `/rmine skull` 进入第 121 层大厅，再从大厅入口进入第 122 层。

## 多人共享规则

- 同一楼层的地形、挖掘状态、怪物数量和梯子由全服共享；
- 电梯进度与阶段奖励按玩家 UUID 独立保存；
- 同时请求尚未生成的楼层时，只有一个生成任务运行，其他玩家进入等待队列；
- 骷髅洞会话只在最后一名玩家离开后结束。

这意味着普通矿层在当天会被其他玩家实际“挖空”，符合共享矿洞玩法，而不是每人一份副本。
